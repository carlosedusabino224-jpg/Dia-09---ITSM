# ITSM — Information Technology Service Management

Um projeto web inspirado em sistemas de suporte e gerenciamento de serviços de TI.
---

## Sobre o projeto

O **ITSM (Information Technology Service Management)** foi desenvolvido como parte do meu desafio diário de projetos para praticar e fortalecer meus conhecimentos em **HTML5 e CSS3**.

A proposta foi criar uma interface organizada, com navegação entre páginas, área de apresentação, formulário de login e uma estrutura visual inspirada em ambientes corporativos de Tecnologia da Informação.

Este projeto representa mais uma etapa da minha evolução na construção de interfaces web e na organização de projetos para portfólio.

## Objetivos

- Praticar a criação de páginas HTML interligadas.
- Desenvolver layouts utilizando CSS.
- Organizar arquivos em pastas separadas.
- Criar uma página de login.
- Trabalhar com navegação entre páginas.
- Desenvolver uma interface com proposta corporativa.
- Consolidar boas práticas de estruturação de projetos web.
